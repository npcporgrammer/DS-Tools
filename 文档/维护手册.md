# 离散作业板 · 维护手册

面向要改这个程序的人（包括几个月后的自己）。讲清楚**为什么这么设计、坑在哪、怎么改**。

---

## 一、技术选型与总体架构

### 1.1 为什么是这套

| 需求 | 结论 |
|---|---|
| 数学排版要对得起作业 | 必须 LaTeX。本机已装 MiKTeX，直接调 `xelatex` |
| 打字时要立刻看到效果 | 浏览器里用 KaTeX 实时渲染 |
| 要能调起 xelatex、读写文件 | 纯网页做不到 → 需要桌面壳 |

于是：**Electron（壳）+ 原生 HTML/CSS/JS（界面）+ KaTeX（预览）+ xelatex（终排）**。

被否决的方案：

- **Word / docx 生成**：公式排版质量差，作业一眼能看出是硬凑的
- **纯网页**：浏览器不能启动子进程，导不了 PDF
- **Python + PySide6**：matplotlib 式排版丑，行内公式编辑体验差
- **Tauri**：需要 Rust 工具链，换来的是更小的体积，不值得

### 1.2 进程模型

```
main.js（主进程 / Node）
   ├─ BrowserWindow ── preload.js ── 渲染进程（Chromium，contextIsolation 开、nodeIntegration 关）
   ├─ 文件系统：Projects/、导出/、.cache/
   └─ child_process.spawn('xelatex')
```

界面拿到的一切能力都经过 `preload.js` 的 `window.api`，渲染进程不直接碰 Node。

## 三、数据流

### 3.1 预览

```
editor.value
  → md2html.render()        （浏览器端，保护性转义）
  → page.innerHTML
  → KaTeX 已在 $…$ 处生成好 HTML
  → fitPage() 计算缩放
```

### 3.2 导出

```
editor.value + meta
  → lib/md2tex.buildTex()   → 完整 .tex
  → 写入 .cache/build-XXXX/homework.tex
  → spawn xelatex（cwd = 该目录，TEMP 也指向该目录）
  → homework.pdf
  → 复制到 导出/<作业名>.pdf
  → shell.openPath() 打开
```

## 四、核心实现细节

### 4.1 `lib/md2tex.js`

**行内处理顺序不能乱**：

1. 先用占位符 `\u0001<n>\u0001` 摘出行内代码和数学公式
2. 再对剩下的纯文本做 LaTeX 转义（`% & # _ { } \ ~ ^`）
3. 再处理 `**粗体**` / `*斜体*`
4. 最后把占位符还原

如果先转义再摘公式，`_`、`%` 会把公式毁掉；如果先处理粗体再转义，`\textbf{...}` 里的反斜杠会被转义掉。

**块级规则**：

| Markdown | 产出 |
|---|---|
| `# ## ###` | `\section*` / `\subsection*` / `\subsubsection*` |
| `$$ … $$` | `\[ … \]`，**内部空行会被剔除**（空行会让 TeX 报 `Missing $ inserted`） |
| ` ```tikz ` | `tikzpicture` 环境 |
| ` ```latex ` | 原样插入（用来写 `\newpage` 等） |
| 其他代码块 | `verbatim` |
| 管道表格 | `tabular`，全 `c` 列对齐 |
| `- ` / `1. ` | itemize / enumerate |
| 段落内换行 | `\\`（**刻意保留**：推导一行一步） |

### 4.2 撤销栈（`src/renderer.js`）

**为什么必须自己写**：点符号、点片段时用的是 `editor.value = ...`，这会**清空浏览器原生的撤销栈**。不自己维护，用户点错一个符号就退不回来。

```js
const U = { stack: [], index: 0, lastTypeAt: 0, LIMIT: 300 };
```

- 每步存 `{v, s, e}`（值 + 选区）
- `historyRecord('type')`：连续输入在 700ms 内合并成一步
- `historyRecord('op')`：插入符号/片段/包裹公式，永远单开一步
- 撤销时 `applySnapshot()` 只写 `value` 和选区，**不会触发 `input` 事件**，所以不会污染历史

新增任何"程序化改文本"的功能，都要在改完后调一次 `historyRecord('op')`。

### 4.3 预览缩放（曾经把应用搞崩过）

早期写法：

```js
pageWrap.style.transform = `scale(${s})`;   // s 由容器宽度算出
pageWrap.style.width = natural;             // 但布局宽度没变 → 撑出横向滚动条
```

滚动条出现/消失会改变 `clientWidth` → 触发 ResizeObserver → 重新算 scale → 滚动条又变……渲染进程 100% CPU 死循环，最后进程被打死。

**现在的写法有三条硬约束**：

1. `.preview-scroll` 用 `overflow-y: scroll`，垂直滚动条**常驻**，宽度不会跳
2. `.page` 是 `position: absolute`，不参与 wrap 的布局尺寸
3. 缩放只由 `previewScroll.clientWidth`（或用户手动设的百分比）单向决定

> 改这段代码时，只要破坏其中任何一条，死循环就会回来。

### 4.4 启动自愈（`main.js` 顶部）

这台机器上有两个环境问题，代码里做了兜底：

**(1) `ELECTRON_RUN_AS_NODE=1`**

某些终端环境会带这个变量，electron.exe 会退化成纯 Node，`require('electron')` 拿不到 `app`。检测到 `!app` 就删掉变量重启自己。

**(2) Chromium 代码完整性校验崩溃**

机器上装过会向 Chromium 进程注入 DLL 的安全软件（腾讯电脑管家等），触发 `RendererCodeIntegrity` 校验，进程直接 `__debugbreak`（异常码 `0x80000003`）。

这两个开关**必须作为真实命令行参数**传入——`app.commandLine.appendSwitch()` 对 sandbox 来说执行得太晚：

```
--no-sandbox --disable-features=RendererCodeIntegrity
```

所以 `main.js` 会在参数不齐时 `spawn(process.execPath, argv + flags)` 重启自己；`启动.bat` 则预先设好 `DMATH_BOOTSTRAPPED=1` 和参数，避免多起一次进程。

### 4.5 xelatex 子进程

```js
spawn('xelatex', ['-interaction=nonstopmode', '-halt-on-error', '-file-line-error', 'homework.tex'], {
  cwd: workdir,
  windowsHide: true,
  env: { ...process.env, TEMP: workdir, TMP: workdir, TMPDIR: workdir }
});
```

三个要点：

1. **`TEMP` 必须重定向**。默认继承的 `%TEMP%` 在某些受管账户/杀软环境下不可写，TeX 写临时文件失败会**在出第 1 页时静默退出**——没有 `!` 报错，日志停在半截，非常难查。指向 `cwd` 就规避了。
2. `-file-line-error` 让错误行变成 `file:line: msg`，解析起来简单。
3. 120 秒超时兜底；日志里出现 `Rerun` 时再跑一遍。

错误解析 `extractErrors()` 会把常见的英文报错翻成中文（未定义命令、缺 `$`、花括号不配对等）。

### 4.6 目录解析

```js
const EXE_DIR = path.dirname(app.getPath('exe'));
const APP_ROOT = path.basename(EXE_DIR).toLowerCase() === 'dist'
  ? path.dirname(EXE_DIR)      // 打包后：<根>/dist/xxx.exe → <根>
  : EXE_DIR;
```

数据目录 `Projects/`、`导出/`、`.cache/` 都挂在 `APP_ROOT` 下。这样重新打包（重建 `dist/`）不会动到作业。

### 4.7 打开文件夹 / 文件

**不要用 `shell.openPath`**。它走 ShellExecute，在受限的进程令牌下会"返回空错误串（=成功）但什么也没做"，或者弹一个「Windows 无法访问指定设备、路径或文件」的系统框。

实测三种方式，**只有 COM 自动化在受限令牌下稳定**：

```js
// 首选：Shell.Application COM（powershell 一行）
(New-Object -ComObject Shell.Application).Explore('<目录>')

// 次选：直接起 explorer.exe
spawn('explorer.exe', [target], { detached: true, stdio: 'ignore' })

// 最后兜底：shell.openPath
```

| 方式 | 受限令牌下 | 说明 |
|---|---|---|
| `shell.openPath` | ✗ 静默失败或弹权限框 | ShellExecute 被拦 |
| `spawn('explorer.exe')` | △ 时好时坏 | 交给已运行的 explorer 处理，可能无声无息 |
| Shell.Application COM | ✓ 稳定 | 走 COM 自动化，不走 ShellExecute |

> 排查时容易误判：`shell.openPath` 的返回值和"窗口有没有出现"是两回事。要验证是否真打开，直接枚举顶层窗口标题比较可靠。

### 4.8 界面

- Office 风格三选项卡：`.tab` 切 `.panel.is-active`
- 所有按钮走**一个事件委托**：`data-act` / `data-snippet` / `data-wrap` / `data-toggle` / `data-zoom`，加按钮不用写新的绑定代码
- 响应式断点 `@media (max-width: 1240px)`：`.panes` 从 `row` 变 `column`，分栏拖拽会自动切换横/竖逻辑（`isStacked()`）

## 五、构建与发布

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

做的三件事：

1. 清空并重建 `dist/`
2. 复制 `node_modules/electron/dist/*` → `dist/`，把 `electron.exe` 改名 `离散作业板.exe`
3. 复制 `main.js`、`preload.js`、`package.json`、`lib/`、`src/`、`vendor/` → `dist/resources/app/`

产物约 **370 MB**（Electron 运行时占绝大部分）。

注意事项：

- **首次准备**：`npm install` 之后如果 `node_modules/electron/dist` 不存在，说明 postinstall 被 npm 的 allow-scripts 策略挡了，手动跑 `node node_modules/electron/install.js`（国内需 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`）。
- `package.json` 的 `name` 决定用户数据目录（`%APPDATA%\discrete-homework-board`），改名会导致设置丢失。
- 图标由 `_dev/make_icon.py` 生成（Pillow）。改颜色/几何后重跑一次，覆盖 `src/icon.ico`。

## 六、扩展指南

### 6.1 加一个符号

`src/renderer.js` 的 `PALETTE`：

```js
{ title: '关系', items: [
  ['≤', '\\le', '小于等于'],            // [显示字形, LaTeX, 悬停提示]
  ...
]}
```

`\u0002`（常量 `C`）代表插入后光标落点，例如 `['⌊', '\\lfloor ' + C + '\\rfloor', '下取整']`。

### 6.2 加一个插入片段

1. `SNIPPETS` 里加一条：`key: ['LaTeX 文本', 是否自动包 $…$]`
2. `src/index.html` 的「插入」面板加按钮：`<button class="rb" data-snippet="key">…</button>`

### 6.3 改主题色

`src/styles.css` 顶部变量：

```css
--w-blue: #2b579a;   /* 主色（Word 蓝） */
--w-canvas: #f3f2f1; /* 文档区底色 */
--w-text: #323130;
```

改 `--w-blue` 一处即可换掉选项卡下划线、主按钮、链接色。

### 6.4 加一个 IPC 接口

三处都要动：

```js
// main.js
ipcMain.handle('xxx:do', async (_e, arg) => { ... return result; });

// preload.js
contextBridge.exposeInMainWorld('api', { ..., doXxx: (arg) => ipcRenderer.invoke('xxx:do', arg) });

// renderer.js
const r = await window.api.doXxx(arg);
```

## 七、已知坑

| 现象 | 原因 | 处理 |
|---|---|---|
| `npm start` / `electron .` 一启动就崩 | 开发模式要经过 `default_app.asar` 引导，这台机器上必崩 | **只能打包后运行**，用 `build.ps1` |
| 双击 exe 没反应 | 环境变量 `ELECTRON_RUN_AS_NODE=1` | 用 `启动.bat`（会清掉） |
| 窗口白屏、进程秒退（0x80000003） | Chromium 代码完整性校验 | 确保带 `--no-sandbox --disable-features=RendererCodeIntegrity` |
| 导出报「编译失败」，日志停在出页处 | 子进程 `%TEMP%` 不可写 | 已把 TEMP 重定向到 `.cache/`，别再改回去 |
| 预览卡死、CPU 100% | 缩放与滚动条互相触发 | 见 4.3，保持"单向依赖" |
| 重新打包后作业不见了 | 数据被写进了 `dist/` | 数据必须挂在 `APP_ROOT` |
| 双击 `启动.bat` 乱码/命令找不到 | `.bat` 里有中文内容 | `启动.bat` 保持**纯 ASCII** 内容 |
| 中文路径编译失败 | —— | 已实测无影响，不是原因 |
| 窗口跑到屏幕外 | 手动改过窗口位置/多屏切换 | 用 `SetWindowPos` 拉回主屏，或重启应用 |
| 点「打开文件夹」没反应 | `shell.openPath` 被 ShellExecute 权限拦住 | 已改成直接起 `explorer.exe`，别再换回去 |

## 八、排障手册

**症状：应用起不来**

```powershell
# 1. 看 exe 是否存在
Test-Path .\dist\离散作业板.exe

# 2. 手动带参数跑，看 stderr
.\dist\离散作业板.exe --no-sandbox --disable-features=RendererCodeIntegrity

# 3. 环境变量是否捣乱
$env:ELECTRON_RUN_AS_NODE      # 应为空
```

**症状：导出失败**

1. 先确认 xelatex 可用：`xelatex --version`
2. 用命令行复现（不经过界面）：

```powershell
node _dev\build-doc.js .\Projects\某作业.md $env:TEMP\test.pdf
```

如果命令行能过、界面不行，问题在 `main.js` 的 `compileToPdf`（多半是 TEMP 或权限）。

**症状：界面行为异常**

F12 打开开发者工具看 Console；或带 `--remote-debugging-port=9222` 启动，用 CDP 直接执行 JS 排查（`_dev/test-undo.js` 是现成例子）。

**症状：打开文件夹/PDF 没反应**

先看是不是 `shell.openPath` 的问题：在应用里执行 `window.api.openPathRaw('C:\Users\')`，如果 `explorerOk` 为真而 `shellError` 有值，就是 ShellExecute 被拦，属于环境问题，不是路径问题。

**症状：想留现场**

设 `DMATH_KEEP_BUILD=1`，导出失败时保留 `.cache/build-*` 目录，可以直接看 `homework.log`。

## 九、改动后的验收清单

每次改完代码，按顺序过一遍：

- [ ] `powershell -ExecutionPolicy Bypass -File build.ps1` 无报错
- [ ] 双击 `启动.bat` 能开窗，且 10 秒内不退出
- [ ] 打字 → 预览实时更新
- [ ] 点一个符号 → `Ctrl+Z` 能撤回
- [ ] 新建一个作业 → 出现在文件列表 → 切换正常
- [ ] 导出 → `导出/` 出现 PDF，能正常打开
- [ ] 拖分栏、把窗口拉到 < 1240px 宽 → 自动变上下分栏
- [ ] 关闭再打开 → 上次的文档自动恢复
