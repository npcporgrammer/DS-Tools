# 离散作业板 · 使用手册

一个专门用来写离散数学作业的桌面工具：左边写 Markdown + LaTeX，右边实时看到 A4 排版效果，一键导出成 PDF。

> 适合的场景：作业里大量出现 $\forall\exists\in\subseteq\cup\cap$ 这类符号、需要真值表、需要画关系图/图论的图、最后要交一份像样的 PDF。

---

## 一、开始使用

### 1.1 前提

- 本机已安装 **MiKTeX**（或 TeX Live），且 `xelatex` 在 PATH 里。
  在 PowerShell 里敲 `xelatex --version` 能出版本号即可。
- 不需要联网，所有依赖都已打包在 `dist/` 里。

### 1.2 启动

双击应用根目录下的 **`启动.bat`**。

首次启动约 3～5 秒。关闭窗口即退出。

> 也可以直接双击 `dist\离散作业板.exe`。程序会自动带上必需的命令行参数重启一次（会闪一下），效果相同。

### 1.3 关闭与保存

编辑内容会**自动保存**（停手约 1 秒落盘）。标题栏文件名后面出现 `*` 表示还有没写完的改动。

```
┌──────────────────────────────────────────────────────────────┐

├──────────────────────────────────────────────────────────────┤

│ 行/列 · 字数 · 状态            适应 ─ ●── + 74%              │  ← 状态栏
└──────────────────────────────────────────────────────────────┘
```

### 2.1 顶栏

| 元素 | 作用 |
|---|---|
| ↶ ↷ | 撤回 / 重做，没得撤时自动变灰 |
| 保存 | 立即存盘（平时也会自动存） |
| 开始 / 插入 / 视图 | 切换功能区 |
| 文件名 | 当前打开的作业 |
| 导出 PDF | 生成 PDF 并打开 |

### 2.2 功能区

**开始**

| 组 | 内容 |
|---|---|
| 文件 | 新建、打开（Projects 文件夹）、保存 |
| 历史 | 撤回、重做 |
| 公式 | 把选中的文字包成行内 `$…$` 或独立 `$$…$$` |
| 输出 | 导出 PDF |
| 帮助 | 语法速查 |

**插入** —— 点一下就把片段落到光标处

分式、根号、求和、矩阵、分段、真值表、证明框架、公式块、TikZ 图。

**视图**

| 组 | 内容 |
|---|---|
| 窗格 | 显示/隐藏符号面板、显示/隐藏预览 |
| 显示比例 | 适应宽度 / 75% / 100% / 140% |

### 2.3 左栏

- **文件**：列出 `Projects/` 里的全部作业，点一下就切换。右侧三个小按钮分别是新建（＋）、打开 Projects 文件夹（⌸）、打开导出文件夹（⇩）。
- 新建时文件名会自动填成当前标题（课程 + 第几次，如 离散数学第4次作业.md），不用每次手打
- **作业信息**：姓名、学号、课程、第几次。填了会自动出现在 PDF 页眉和标题里。
- **符号面板**：按常用/逻辑/集合/关系/数论/图论/希腊字母/箭头/结构/块分组。

### 2.4 状态栏

左边是光标位置和字数，右边是缩放滑块。拖滑块或点「适应」都能改预览大小；「适应」会随窗口宽度自动缩放。

## 三、写文档

### 3.1 基本语法

```markdown
# 一级标题        ## 二级标题        ### 三级标题

行内公式：$x \in A$
独立公式（居中，独占一段）：
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

**加粗**   *斜体*   `代码`

- 无序列表
1. 有序列表

| $p$ | $q$ | $p \land q$ |
|---|---|---|
| T | T | T |

---
```

**段落里的单个换行会被保留**——推导一行一步时非常方便，不用敲两个空格。

**特殊字符 `% & # _ { } \` 直接写**，导出时自动转义，不会报错。

### 3.2 公式

行内用 `$…$`，独立用 `$$…$$`。常用对照：

| 想要 | 打 |
|---|---|
| ∀ ∃ | `\forall` `\exists` |
| ∈ ∉ ⊆ ⊂ | `\in` `\notin` `\subseteq` `\subset` |
| ∪ ∩ ∅ | `\cup` `\cap` `\varnothing` |
| ¬ ∧ ∨ → ⇔ | `\neg` `\land` `\lor` `\to` `\Leftrightarrow` |
| 幂集 | `\mathcal{P}(A)` |
| 取整 | `\lfloor x \rfloor` `\lceil x \rceil` |
| 组合数 | `\binom{n}{k}` |
| 整除 | `a \mid b` |
| 逆关系 | `\beta^{c}` 或 `R^{-1}` |
| 关系对 | `\langle x,y\rangle` |

### 3.3 符号怎么打最快

**点左边面板**。每个按钮的悬停提示里写着对应的 LaTeX 命令。

面板会自动判断光标位置：

- 光标**在公式里** → 直接插入 `\forall`
- 光标**在正文里** → 自动包成 `$\forall$`，不用自己补美元符号

### 3.4 画图

三个反引号加 `tikz`，里面写 TikZ 代码。预览里显示为一个代码卡片，**导出 PDF 时才真正渲染成矢量图**。

````markdown
```tikz
\foreach \x/\y/\n in {0/0/a, 2.4/0/b, 1.2/1.9/c}
  \node[circle,draw,inner sep=1pt] (\n) at (\x,\y) {$\n$};
\draw[->] (a) -- (b);
\draw[->] (b) -- (c);
\draw[->] (c) -- (a);
```
````

### 3.5 直通 LaTeX

需要 `\newpage`、`\vspace{1cm}` 这类命令时，用 `latex` 代码块，内容会原样塞进 `document` 里：

````markdown
```latex
\newpage
```
````

## 四、撤回与重做

- `Ctrl+Z` 撤回，`Ctrl+Y`（或 `Ctrl+Shift+Z`）重做
- 顶栏 ↶ ↷ 和「开始 → 历史」里也有

规则：

- **连续打字算一步**（停手约 0.7 秒才断开）
- **每次插入符号、每个片段算一步**，点错一个符号按一下就能退掉
- 保留最近 300 步

## 五、文件管理

所有作业统一放在应用根目录（和 `启动.bat` 同级）：

```
操作板/
├─ Projects/                    ← 作业源码 .md
│   ├─ 离散数学作业.md
│   └─ 关系的表示.md
├─ 导出/                        ← 导出的 PDF
│   └─ 关系的表示.pdf
├─ .cache/                     ← 编译临时文件，可随时删
└─ dist/                       ← 程序本体
```

| 操作 | 怎么做 |
|---|---|
| 新建 | 点文件栏的 ＋，填个名字 |
| 切换 | 点文件列表里的条目（切换前自动保存当前这份） |
| 删除 | 鼠标移到条目上，右侧出现 **×**，点一下并确认 |
| 打开文件夹 | 文件栏右上角的 ⌸ / ⇩ |
| 改名 / 删除 / 备份 | 点 ⌸ 用资源管理器操作，列表会自动刷新 |
| 丢进 git / 网盘 | 直接对 `Projects/` 做就行 |

重新打包（`build.ps1`）只重建 `dist/`，**不会碰** `Projects/` 和 `导出/`。

## 六、导出 PDF

点「导出 PDF」或 `Ctrl+E`。

- **不需要选路径**：PDF 直接生成到 `导出/<作业名>.pdf`，同名覆盖，导完自动打开
- 编译约 1～2 秒
- 生成的是标准 LaTeX 排版：中文字体、公式、TikZ 图都是矢量

### 报错了怎么办

出错时会弹出一条可读提示，带**行号**和中文解释，比如：

| 提示 | 意思 |
|---|---|
| 有未定义的 LaTeX 命令 | 命令拼错了，或该宏包没装 |
| 数学公式缺少配对的 `$` | 这一段有落单的美元符号 |
| 花括号不配对 | 检查 `{` 与 `}` |
| 找不到文件 | `\includegraphics` 之类引用的文件不存在 |

## 九、AI 助手（可选）

应用内置了一个 AI 助手窗格，需要你自己填 API Key 才能用。

**打开**：视图 → 窗格 → 「AI 助手」

**首次配置**：点窗格右上角的 ⚙，填三样东西

| 项 | 说明 |
|---|---|
| Base URL | 接口地址，例如 `https://api.deepseek.com` |
| 模型 | 例如 `deepseek-chat` 或 `deepseek-reasoner` |
| API Key | 你在服务商后台申请的 Key |

预设里已经带了 DeepSeek / OpenAI / Moonshot，选中会自动填好前两项；要对接别的服务，选「自定义」，只要它兼容 OpenAI 的 `/chat/completions` 接口就行。

**怎么用**

- **带上当前文档**（默认勾选）：把正在编辑的整篇文档一起发给 AI，超过 6000 字会截断
- 直接提问，或先在编辑器里**选中一段文字**再问——选中的内容会自动带进上下文
- `Ctrl+Enter` 发送
- 回答里的「思考过程」能不能看到取决于模型：`deepseek-reasoner` 会边想边输出，`deepseek-chat` 不会
- 回答右下角两个按钮：**插入到光标处**（按 Markdown 原文插入，公式接着就能渲染）、**复制**

**关于密钥**

- 存在应用目录的 `ai-config.json`，默认用 Windows 凭据加密（DPAPI），换机器解不开
- 该文件已加入 `.gitignore`，不会被提交
- 换 Key 就直接填新的；留空表示保留原 Key

> 注意：AI 的回答不一定正确，尤其是证明步骤的严谨性，交作业前自己过一遍。
## 十、常见问题

**Q：双击没反应 / 一闪就没了？**
从 `启动.bat` 启动，别直接点 `dist` 里的 exe（虽然通常也行）。若仍不行，看第十节的「导出失败」排障，或直接用命令行运行 `启动.bat` 看报错。

**Q：导出提示「找不到 xelatex」？**
没装 MiKTeX，或 `xelatex` 不在 PATH。装好 MiKTeX 后重开应用。

**Q：中文显示成方块？**
系统缺中文字体。控制面板补装「宋体 / 黑体」即可。

**Q：预览和 PDF 长得不完全一样？**
预览用 KaTeX 渲染公式，PDF 用真正的 LaTeX。字形和细节会有微小差异，**以 PDF 为准**。

**Q：点「打开文件夹」没反应？**
程序会直接调起资源管理器。如果仍然没弹出，可能是系统权限拦住了（旧版程序用的系统接口在某些账户下会被挡）。文件本身都在 `Projects/` 里，手动打开也可以。

**Q：文件列表没更新？**
点一下任意文件切换，或重启应用。保存时会自动刷新。

**Q：能把它放到副屏吗？**
能，拖过去就行。宽窄会自动适配。
